1. 系统定位

Clash 流量簿是现有 Clash Verge Rev 的独立本地统计伴侣。官方 Clash 安装与路由配置保持原状，由独立应用读取 Mihomo 活动连接，积累本机用量历史。它只统计确定经过代理节点的流量，可按日期、时分、订阅、节点与应用组合查询。

此系统提供连接快照的增量统计，不是网卡抓包器、连接审计日志或机场计费系统。历史从采集启动后积累，无法恢复安装前和采集中断期间的完整用量。

3. Next.js 与 shadcn/ui

0.2.0 使用 Next.js 16.3.5 + React 19.3.0 + TypeScript。前端以 output: export 构建，运行时不启动 Node.js，也不使用 Server Actions 或动态服务端路由。Python 提供所有统计与写入 API，SQLite schema 和流量算法保持原样。

shadcn/ui 的 new-york-v4 组件源码来自官方 registry，存放于 frontend/src/components/ui，不是运行时 CDN。使用 Button、Card、Dialog、AlertDialog、Select、Tabs、Input、Label、Badge、Table、Popover、Calendar 等组件；Radix UI 处理弹窗焦点、键盘和下拉交互，React Day Picker 提供中文日历。Tailwind CSS 4 和全局主题统一绿色配色、大字号与间距。图表使用 Recharts 3；日历热力图为带日期按钮和可访问标签的 React 业务组件。

共享根布局持有侧栏与 TanStack Query。总览、明细、归属、存储和说明采用客户端路由；筛选参数随 URL 保留，统计查询缓存 10 秒，活动页面每 5 秒刷新。过期查询可以展示上次结果，但会显式提示并禁用旧结果上的下钻操作。偏好读写沿用现有 API，写入串行处理，失败显示提示。

Python web_assets.py 在启动时建立导出资源白名单。/details/ 等路径映射到对应 index.html，Next 的 JS/CSS 和路由数据一同本地提供。内联启动脚本使用 SHA-256 CSP 哈希许可，未开放 unsafe-inline 脚本或 unsafe-eval；主机、Origin、CSRF 校验继续保留。

构建产物位于 clash_traffic/static/ui，普通源码运行直接读取此目录。原有单页文件仅保留为构建缺失时的开发兼容入口，桌面打包要求 Next 导出存在。旧 Flatpickr 不参与新界面。

前端需要现代 WebKit（Safari 16.4 或以上能力）。0.2.0 安装包最低系统声明为 macOS 13.3，实际在本机 macOS 26.6.2 检查；未验证其他系统。参考 Next 静态导出、shadcn Next 安装、Tailwind 兼容性。

4. 计数与归属

代理范围

读取实际连接的代理链，结合 /proxies 类型过滤策略组、DIRECT、REJECT、PASS 等。至少确认存在一个实际代理节点才计入。路由无法识别时不混入代理总数。

增量算法

以连接 ID 保存上次累计上传/下载。连续采样时计算差额，相同快照不重复计数。首次运行、服务重启、时钟倒退或中断超过 5 秒，重新建立基线；不把已经存在的连接历史累计值计到当前分钟。计数回退时重建该连接基线，不产生负流量。

新连接只有在开始时间落在两次采样之间时，才计入它当前的已知累计值。连接从快照消失时不虚构最终流量。跨分钟的采样增量按时长比例分配，整数余数归末桶，保持已采样字节总数不变。

订阅、节点和应用

以运行配置和本地订阅中的服务器、端口、协议、认证身份建立匹配，使用本机密钥的 HMAC 摘要持久化身份。不会把服务器和密码原文存到历史库。Provider 来源也从本地配置核对，不额外访问订阅地址。

已建立连接沿用首次识别结果，避免切换订阅后把旧连接改记到新来源。无法确认来源的显示“归属待确认”。节点名称相同不代表身份相同。多跳连接只计一次，不代表每一跳机场的各自扣费量。

应用根据 Mihomo 的进程元数据识别，尽量从最外层 .app 读取名称和 Bundle ID，把辅助进程归并到主应用；无法识别时保留进程名或显示未知应用。

手动指定订阅写入覆盖表，在查询时替换归属，影响该节点的全部历史与后续数据。恢复自动识别即删除覆盖，原始采样归属保留。

5. 数据与时间模型

数据表 内容
usage 分钟、节点、订阅、应用、代理链、归属依据、上传与下载字节
coverage 每分钟有效采集覆盖秒数，上限 60
events 采集间断、重启等事件
subscriptions 已识别订阅的 ID 与显示名称
overrides 节点身份到人工指定订阅的映射
state 清理策略、首次启动时间、服务状态、最近清理记录等

当前 schema 版本为 1，SQLite 使用 WAL、synchronous=NORMAL。每轮采样在事务内累计，文件锁防止同一数据目录重复运行。单进程中通过锁协调采集、查询与清理。

分钟用 Unix epoch 存储，查询和展示统一使用 Asia/Shanghai。前端日期选择只传 YYYY-MM-DDTHH:MM 的墙上时间，后端解释为北京时间；不会把浏览器本地时区的 UTC 偏移混入接口。

查询范围为左闭右开 [from,to)，1 分钟至 366 天。粒度为 minute、quarter、hour、day；auto 在两天以内按小时，否则按天。细粒度超过 400 个时段会拒绝查询。旧版仅日期参数的结束日期仍按包含整天兼容；当前界面始终发送日期加时间。

采集覆盖表示记录器在线时间，不代表实际网络字节完整率，也不受应用/节点筛选影响。

6. 本地接口

方法 路径 说明
GET /api/status 连接状态、最近采样、临时 CSRF 令牌
GET /api/options 可筛选的订阅、应用、节点及覆盖
GET /api/summary 汇总、时段趋势、前 50 名排行、覆盖与事件
GET /api/details 分页聚合明细，每页 50 行
GET /api/export.csv 当前范围与筛选的全部汇总，字节单位
GET /api/storage 数据库空间、历史日期、设置与最近清理
POST /api/override 设置/撤销节点的订阅覆盖
POST /api/settings 保存保留天数与空间上限，并立即维护
POST /api/cleanup 清理时间范围或全部；必须 confirm:true

查询参数包括 from、to、granularity、group、subscription、app、node，明细另有 offset。ID 应来自 /api/options，不能用显示名称替代身份。

POST 要求同源 Origin 和有效 X-CSRF-Token，请求体最大 4096 字节。Host 只接受固定本机端口的 localhost/127.0.0.1。静态资源以明确白名单提供，包括三份日期组件资源，不允许任意文件读取。CSP 禁止远端脚本及嵌入框架，未开放 CORS。

这是面向当前 Mac 用户的本地服务，并非有账号隔离的多用户系统；同机可访问回环端口的进程仍应视为本地信任边界内。

7. 空间维护与生命周期

默认保留 180 天、上限 256 MB。每分钟先删过期历史，再检查数据库加 WAL/SHM 空间；超限时按最早分钟删除并压缩，目标约为上限 80%。程序文件不计入；日志独立轮转约 3 MB。保留天数为 0 不取消空间上限。

清理删除相应范围的用量、覆盖和相关事件；保留配置、订阅覆盖与身份密钥。正式数据目录独立于 .app，因此替换应用不会清空数据库。

LaunchAgent 在当前用户登录时启动，可在服务异常退出后重启。关闭界面不会停止采集；电脑休眠、Clash 停止或权限不可用时无法采集，恢复后重新建基线。界面通常每 5 秒刷新，弹窗操作期间暂停界面自动刷新以保持控件稳定，后台采集不受影响。

8. 已知边界与验证

  • 快照间结束的短连接和连接尾部可能漏计；不会根据缺失信息估算账单。
  • 配置每 5 秒刷新，切换附近的新连接可能短暂使用旧归属索引。
  • 本机普通订阅已验证；动态 Provider、合并配置或脚本改写须进一步按实际环境验证。
  • 不保存目标访问域名、IP、订阅 URL、密码或进程完整路径；会保存应用、节点、订阅显示名称和代理链。
  • 多跳不重复累加，不能用这里的某条订阅总数直接核算多机场扣费。
  • SQLite NORMAL 在系统掉电时可能丢失最近提交，定期备份比 CSV 导出更完整。
  • 当前只构建 arm64，未验证其他 Mac 和所有旧系统版本。

现有 40 项 Python 测试涵盖增量、过滤、跨时段、归属覆盖、容量清理、CSV、HTTP 安全边界与 Next 静态资源白名单；前端另有模型测试和 TypeScript 类型检查。更细的代码级架构见源码根目录 ARCHITECTURE.md，操作方法见 使用文档，运行与构建见 运行文档。

9. 菜单栏生命周期

原生 NSStatusItem 提供模板图标，自动适应系统菜单栏外观，实例由应用持有。菜单每 5 秒通过本机 /api/status 获取状态与速率，异步请求不阻塞界面。关闭最后一个窗口不终止应用；显式退出清理定时器和状态项，独立 LaunchAgent 继续运行。菜单栏显隐偏好保存在 macOS 用户偏好中，不影响数据库。菜单栏功能不增加新的登录启动项。

0.1.4 日历与聚合更新

新增本年范围、本月/本年的每日流量日历，趋势可切换柱状图与折线图。明细默认折叠代理链差异；应用可合并或分别统计，点击来源可核对原始编号与链路。偏好存于本机，历史数据保持原有结构。详细操作、颜色阈值与限制见 聚合规则。

GET /api/preferences 读取显示偏好；POST /api/preferences 以现有 Origin 和 CSRF 校验保存枚举字段 chart_type（bar/line）、app_mode（combined/separate）、detail_mode（summary/sources）。查询的 app_mode 和 detail_mode 显式决定视图，偏好不会隐式改变 API 结果。/api/options 新增 apps_combined；/api/summary 新增独立按北京时间聚合的 daily；/api/details 新增 source_count、identity_count、first_seen、last_seen。SQL 查询时归并，无 schema 迁移。新增 6 项业务与接口测试，总计 37 项通过。
